# ADR-051 — AI-Assisted Development

## Status
Accepted

## Decision

AI coding assistants may participate in FluxDine development but shall operate under the Architecture Bible and Development Standards.

Supported assistants may include:

- Cursor
- Claude
- ChatGPT
- GitHub Copilot
- Future approved AI tools

## Consequences

AI-generated code remains subject to the same testing, review, security, and architectural requirements as human-written code.
